# 🍂 LEAF FALL

> Часть вселенной **PIXEL FOREST**. Поймай осень в свои руки.

[![Играть](https://img.shields.io/badge/🎮_ИГРАТЬ-4CAF50?style=for-the-badge)](https://matiazzqq.github.io/leaf-fall/)

## 🌿 О игре
Вместо мрачного неона — мягкие цвета осени. Твоя задача — быстро реагировать и ловить падающие листья, избегая тяжелых камней. Золотые листья дают бонусные очки!

## ✨ Особенности
- 🎨 **Уютный дизайн**: Градиенты заката и мягкая палитра цветов.
-  **Динамическая сложность**: Чем дольше играешь, тем быстрее падают объекты.
- 🔊 **Природные звуки**: Генерируемые через Web Audio API (мягкие "попы" и гулы).
- 💥 **Эффекты частиц**: Взрывы листьев при клике и тряска экрана при ошибке.
- 📱 **Mobile Ready**: Полная поддержка сенсорного управления.

## 🕹 Управление
- **Клик / Тап**: Ловить объект под курсором.
- Цель: Листья ✅ | Камни ❌
